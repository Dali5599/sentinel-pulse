# Contributing Guidelines

Thank you for considering contributing to this open-source project!

## How to Contribute
1. Fork the repository on GitHub.
2. Clone your fork locally and create a new feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. Commit your changes with clear, structured commit messages following conventional commits (`feat:`, `fix:`, `docs:`, `test:`).
4. Ensure all test suites pass locally.
5. Push your branch to GitHub and open a Pull Request.

## Code Quality Standards
- Code must be typed, well-commented, and formatted.
- Avoid introducing unnecessary heavy external dependencies.
- Include unit tests for any new feature or bug fix.
